# GitHub Pages Deployment
A simple static site deployment example using GitHub Actions and GitHub Pages.

## Getting Started
1. Push changes to the `main` branch.
2. Change `github-pages-deployment/index.html` to update the website.
3. Run the workflow manually from the GitHub Actions tab if you want to test it right away.

The site is published at the GitHub Pages URL for this repository.
[Here](https://jstin9.github.io/devops-lab/)
